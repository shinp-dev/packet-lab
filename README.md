# Packet Lab

Android端末内の通信を、利用者が明示的に開始・停止して確認するローカルVPN解析ツール。
通信エンジン・結果画面は [PCAPdroid](https://github.com/emanuele-f/PCAPdroid) の固定コミットを利用します。

## Windowsからビルド

Git、Python 3、JDK 17、Android SDK Platform 37、NDK 28.2.13676358、CMake 3.22.1 が必要です。
Android SDKはAndroid StudioのSDK Manager等で準備してください。

```powershell
git clone https://github.com/shinp-dev/packet-lab.git
cd packet-lab
py setup.py --build
adb install -r .\packet-lab-android\app\build\outputs\apk\standard\debug\app-standard-debug.apk
```

初回のみ上流ソースとサブモジュールを取得します。生成ディレクトリはGit管理対象外です。
上流のビルド要件は変更していません。ビルドが未確認の段階です。

## 使い方

1. Packet Labを開き、初期設定を完了し、通知権限を許可。
2. 右上メニュー「記録モード設定」で詳細（既定）または軽量を選ぶ。
3. 「操作パネルを表示」を選択。重ねて表示する権限を許可した後、もう一度選択。
4. 他アプリ上の操作パネルで「詳細開始」または「軽量開始」を押す。初回のVPN許可はAndroidの画面で行う。許可済みで他のVPNが動いていなければ、パネルから直接開始する。
5. 他アプリを操作する。赤い「停止」ボタンは記録中を示す。
6. 停止すると通信記録が終了し、他のアプリは通常の通信経路に戻る。
7. 「結果」で本体の接続一覧を開く。詳細モードでは上流の接続詳細・HTTPログ・ペイロード表示を利用する。
8. 「×」は記録を停止して操作パネルを閉じる。ドラッグ用の「≡」で位置を調整できる。

## 設計・制限

- Android 8.0以上で操作パネルが利用可能。VPNとパネルはそれぞれフォアグラウンドサービスとして実行し、通知が表示される。
- 起動直後の自動記録、外部からの記録開始API、ブート時自動起動、Always-on VPNを無効化。
- ライブ記録はroot不要、IPv4/IPv6、端末内処理、外部エクスポータ・SOCKSプロキシ・TLS復号は無効。
- 詳細記録は平文の個人情報や認証情報を含む可能性がある。自分の端末・許可された通信だけで利用すること。記録を他人と共有する際は内容に注意。
- 直前の結果は上流のメモリ内接続レジスタに保持される（最大1024接続に設定）。新規記録やプロセス終了で失われる。詳細ペイロードは上流のメモリ保護に依存し、固定バイト上限ではない。
- 軽量モードではフルペイロード・HTTPログを保持しない。HTTPSの本文は暗号化されたまま。
- 他のVPNとの同時使用はできない。既存VPNがあれば確認を表示する。
- この版の自動PCAP保存、複数セッションの永続化、独自の結果画面は未実装。上流設定画面には使わない設定項目が残る。
- 実機でVPN許可、開始/停止、通知からの停止、他VPNの接続、権限取消、通信速度、ボディ表示を確認する必要がある。
